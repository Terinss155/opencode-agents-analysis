# Справочники статусов: заказ, позиция заказа, Mindbox, WMS

**Проект:** «Возвраты 2.0» / «Омниканальный возврат»  
**Версия:** 1.2  
**Последнее обновление:** 02.10.2026

## 1. Назначение

Файл является единым источником расшифровки числовых и символьных статусов заказа и его позиций, их маппинга на статусы Mindbox и статусов WMS. Проектные документы содержат только значения, необходимые для конкретного сценария, и ссылаются на этот справочник.

`id` — идентификатор строки справочника. Для расшифровки статуса из бизнес-таблицы используется `internal_id` (для WMS — `code`), поэтому искать строку справочника по совпадению с `id` некорректно.

Статус возврата WMS хранится **на уровне заказа** (`cms_orders.return_status_wms`), а не позиции.

### Наблюдения для возвратов

- Позиция `9` «ВОЗВРАТ (если был отгружен)» почти при всех статусах заказа даёт Mindbox `401`. Исключения: заказ `20` → `505`, `21` → `411`, `22` → `411`, `40` → `504`, `53` → `322`, `48` и `55` → `503`, `50`–`52` → `701`/`702`/`703`. Для заказов `9`, `11`, `23` строки с позицией `9` нет.
- Позиция `5` «Возврат (отгруженного)» замаплена только для заказов `50`–`53` (`53` → `322`). При заказе `17` «Заказ выполнен» маппинга для позиции `5` нет.
- При заказе `17` «Заказ выполнен» (по `ADR-RET-039` статус исходного заказа при возврате остаётся таким): позиции `1`, `2`, `10`, `11` → `311`, `9` → `401`, `13` → `402`, `3` → `502`, `4`, `12`, `14` → `501`.
- При текущих возвратных статусах заказа `18` «Полный возврат» позиции `1`, `2`, `10`, `11` получают `401` — как возвращённые; при `19` «Частичный возврат» и `31` «Возврат из ЛК» — `311`/`311`.
- **Вывод для TO-BE.** Если статус заказа остаётся `17`, а позиции получают «Заявка на возврат» и «Возвращено», Mindbox получит: для кода `9` — `401`; для кода `5` — ничего (строки нет); для нового `internal_id` — ничего, пока не добавлены строки маппинга. Решение о кодах и новых строках `cms_mb_statuses_map` — задача SA (`ADR-RET-039`, BRD `OQ-47`).

Сопоставление: `cms_orders.return_status_wms = code`. Значение приходит из 1С при обмене заказом и хранится на уровне заказа.

| `id` | `code` | `title` |
|---:|---|---|
| 1 | `1` | Создано |
| 2 | `2` | Прибыл |
| 3 | `3` | Приемка по местам |
| 4 | `4` | Приемка по позициям |
| 5 | `5` | Принят |
| 6 | `6` | Принят с расхождениями |
| 7 | `7` | Размещение |
| 8 | `8` | Закрыт |
| 9 | `9` | Закрыт с расхождениями |
| 10 | `11` | Отменен |

Для TO-BE статусов позиции возврата («В процессе приёмки» → «Принято на склад», `ADR-RET-040`) кандидаты среди статусов WMS: `3` «Приемка по местам», `4` «Приемка по позициям», `5` «Принят», `6` «Принят с расхождениями». Сопоставление не утверждено.
