# ADR-RET-049: Новый возврат запускается одновременно на сайте и в мобильном приложении — Mobile First не применяется

## Контекст

System Analyst одна описывает и сайт, и мобильные приложения; логика оформления возврата в них
разная, документации нет. Project Manager спросила, нельзя ли по принципу Mobile First сначала
запустить возврат в мобильном приложении.

## Решение

Принцип Mobile First к возвратам не применяется: новый процесс возврата запускается и на сайте, и в
мобильном приложении. Возврат — работа с деньгами клиента, а не дополнительная функция, которую можно
дать только в одном канале.

## Последствия

### Положительные

- Клиент получает одинаковый процесс возврата во всех каналах.
- Не нужно поддерживать старый и новый процесс параллельно в разных каналах.

### Отрицательные и риски

- Описывать требования и реализовывать нужно сразу для двух каналов — нагрузка на System Analyst
  (Head of PMO обещала искать помощь).
- Логика сайта и МП расходится, поэтому общий бэк приходится проектировать под обе.

## Рассмотренные альтернативы

### Mobile First: сначала мобильное приложение

- **Результат:** отклонена.
- **Причина:** возврат — работа с деньгами клиента, его нельзя запускать только в одном канале.

## Условия пересмотра

- Бизнес согласует поэтапный запуск по каналам.
