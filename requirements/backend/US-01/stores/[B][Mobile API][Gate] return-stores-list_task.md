# [B][Mobile API][Gate] Форма возврата. Метод для получения списка магазинов, принимающих возвраты

## Цель

Проксировать запрос мобильного приложения на бэк сайта для получения списка магазинов, принимающих возвраты, в выбранном городе возврата.

## Описание реализации

```
Gate: GET /api/v1/stores/returns?city_fias={city_fias}
Site: GET /mobile/stores/returns?city_fias={city_fias}
```

## Тестирование

**Предусловия**
- Выполнена задача `[B][Mobile API] Форма возврата. Метод для получения списка магазинов, принимающих возвраты`.
- В городе есть магазины с признаком «Принимает возвраты».

**Критерии приёмки**
- Запрос через гейт проксируется в метод монолита.
- Ответ гейта совпадает с ответом прямого запроса в монолит при тех же query-параметрах и заголовках — как для успешного ответа, так и для ошибки без `city_fias`.
- Метод проксирования отражён в swagger нового гейта.
