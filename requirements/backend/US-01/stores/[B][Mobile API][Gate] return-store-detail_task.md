# [B][Mobile API][Gate] Форма возврата. Метод для получения подробной информации о магазине

## Цель

Проксировать запрос мобильного приложения на бэк сайта для получения подробной информации о магазине для карточки магазина в форме возврата.

## Описание реализации

Реализовать проксирование метода по задаче `[B][Mobile API] Форма возврата. Метод для получения подробной информации о магазине`. Контракт, логика и ошибки описаны в ней и здесь не повторяются.

```
Gate: GET /api/v1/stores/{store_code}
Site: GET /mobile/stores/{store_code}
```

Гейт только проксирует запрос:
* параметр пути `store_code` передаётся в монолит без изменений;
* заголовки авторизации и платформы (`x-platform`, `x-version`) передаются в монолит;
* ответ монолита (конверт `success` / `result` и ошибки) возвращается без изменений.

{red}(Путь на гейте согласовать с бэкенд-командой.)

## Тестирование

**Предусловия**
- Выполнена задача `[B][Mobile API] Форма возврата. Метод для получения подробной информации о магазине`.

**Критерии приёмки**
- Запрос через гейт проксируется в метод монолита.
- Ответ гейта совпадает с ответом прямого запроса в монолит при том же `store_code` и заголовках — как для успешного ответа, так и для ошибки «Магазин не найден».
- Метод проксирования отражён в swagger нового гейта.
