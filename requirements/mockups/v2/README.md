**Статус: зарегистрирован состав набора; исходные изображения ещё не сохранены в этой папке.** Изображения доступны для визуального просмотра в сообщении, но пути к исходным файлам вложений не предоставлены. В `requirements/` и доступной временной папке новые файлы не обнаружены. Для сохранения без перерисовки и потери качества нужны файлы PNG/JPG, доступные по локальному пути, либо ссылка на скачивание исходников.

## Замечания при использовании

- На экране оформления карточки товаров полные, как на шаге выбора; дополнительно отображается выбранная причина возврата. Не использовать краткое представление из предыдущего макета вместо этого набора сведений.
- Макеты созданы для примеров данных. Показанные суммы, даты, номера, цены и PIN не являются новыми бизнес-правилами или форматом нумерации.
- В карточках возврата есть действия «Показать штрихкод» / «Показать QR-код», а коды представлены отдельными модальными окнами. Это расходится с ранее сформулированным требованием выводить код развёрнутым без дополнительных кликов. Требуется определить итоговый вариант, не отменяя текстовое требование молча.
- В макете 5Post инструкция содержит упоминания СДЭК и штрихкода. Этот текст нельзя автоматически переносить в требования 5Post как согласованный канальный текст.
- Заглушка «Дополнительный текст» в окнах кодов — не согласованный клиентский текст. Состояние ожидания генерации кода в присланном наборе не показано.
- Отсутствие попапа смены города в этих шести изображениях не отменяет подтверждённую логику сохранения доступного способа и повторного выбора ПВЗ.
