# ADR-RET-008: Предзаполнение способа и адреса возврата на основе исходного заказа

## Контекст

При оформлении заявки на возврат клиенту необходимо выбрать способ (курьер, ПВЗ и т.д.) и конкретную точку возврата. Для ускорения и упрощения клиентского пути обсуждалась возможность автоматически предвыбирать способ возврата, основываясь на данных исходного заказа.

Однако не все способы доставки доступны для возврата (например, доставка Яндекс), а некоторые конкретные ПВЗ работают только на выдачу и не принимают возвраты.

## Решение

Система должна предвыбирать способ и адрес возврата по следующим правилам:
1. Если заказ был доставлен в ПВЗ и этот конкретный пункт принимает возвраты — данный ПВЗ предвыбирается по умолчанию.
2. Если заказ был доставлен курьером — по умолчанию предвыбирается возврат курьером на тот же адрес.
3. Если исходный способ доставки недоступен для возврата (например, Яндекс) или исходный ПВЗ не принимает возвраты, предзаполнение не производится — клиент выбирает способ самостоятельно из доступного списка.

Клиент в любом случае может изменить предвыбранный способ на другой доступный.

## Последствия

### Положительные
- Упрощается и ускоряется процесс оформления возврата для большинства клиентов (бесшовный UX).
- Снижается когнитивная нагрузка: клиенту предлагается уже знакомый и удобный ему способ.

### Отрицательные и риски
- Требуется дополнительная проверка на стороне логистики: принимает ли конкретный ПВЗ из заказа возвраты.
- Возможны конфликты при смене способа (например, при переключении с ПВЗ на курьера нужно корректно подтянуть адрес из заказа).

## Рассмотренные альтернативы

### Всегда предвыбирать самый дешевый для компании способ (например, ПВЗ)
- **Результат:** отклонена.
- **Причина:** если клиент заказывал курьером, логично, что ему удобно отдать возврат тоже курьером; принудительный предвыбор ПВЗ ухудшит UX.

## Условия пересмотра

- Логистика подтверждает или опровергает возможность получить признак «ПВЗ принимает возвраты» для конкретного пункта на момент оформления возврата.
- В способы доставки заказа, участвующие в предвыборе, добавляется канал, для которого правило предвыбора не определено (например, доставка Яндекс становится доступна для возврата).
