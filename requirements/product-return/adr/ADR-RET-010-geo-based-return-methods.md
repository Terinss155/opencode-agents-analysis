# ADR-RET-010: Управление доступностью способов возврата по Geo ID

| Поле | Значение |
|---|---|
| **Статус** | Принято |
| **Дата решения** | 10.09.2026 |
| **Владелец решения** | Product Manager — Катя Филатова; согласующие: System Analyst — Елена Васильева |
| **Область** | Продукт / Логистика / Админка |

## Контекст

У компании есть специфика доставки и возвратов для удалённых регионов. Например, в Калининграде курьерские возвраты сопряжены с длительным и непредсказуемым процессом растаможки через границу. В связи с этим возникает потребность ограничивать определенные каналы возврата (например, оставлять только Почту России или возврат в магазин) для конкретных городов.

## Решение

В админке сайта (или сервисе логистики) должна быть реализована единая настройка управления доступными способами возврата в зависимости от геолокации (Geo ID или города) клиента. 
Бизнес должен иметь возможность вручную включать и отключать конкретные способы (курьерка, ПВЗ, Почта РФ) для выбранного региона. Клиент в интерфейсе должен видеть только те способы, которые разрешены для его Geo ID.

## Последствия

### Положительные
- Минимизируются логистические риски (например, зависание товаров на таможне).
- Появляется гибкий инструмент для быстрого реагирования на изменения в работе транспортных компаний в регионах.

### Отрицательные и риски
- Требуется дополнительная доработка админки или сервиса логистики для ведения справочника Geo ID и привязки к ним способов возврата.

## Условия пересмотра

- Появляется техническая возможность автоматически (без ручной настройки) ограничивать каналы по
  региону на основе данных транспортных компаний о простоях или таможенных задержках.
- Число регионов с ограничениями существенно вырастает и ручное управление по Geo ID перестаёт
  справляться со скоростью изменений.
