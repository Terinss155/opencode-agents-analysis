# Требования: возврат товара и возврат денежных средств

Версия бандла: 5 · Дата: 11.09.2026 · Статус: Черновик

Единый логический документ для согласования будущего процесса возврата. Файлы разложены по
подпапкам по типу артефакта; связь между вкладками — по стабильным ID (`BO-`, `PP-`, `BR-`,
`OQ-`, `US-`, `UC-RET-`, `ADR-RET-`) и ссылкам. Расшифровка префиксов — в легенде матрицы трассируемости.

Собран из несогласованного BRD заказчика и логов согласования в `../drafts/` | Черновик (v4) |
