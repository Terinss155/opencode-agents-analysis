# Деление строки позиции заказа при возврате части одинаковых изделий

Возвраты 2.0 · 11.11.2026

Когда клиент возвращает часть одинаковых изделий одной позиции заказа, возвращённые единицы отделяются от оставшихся новой строкой позиции заказа. Оставшиеся единицы клиент возвращает следующей заявкой ([разбор встречи 11.11.2026](<../../meetings/[2026-11-11 13-01] Вопросы по обмену плат. реквизитами_summary.md>), тема 11; [разбор PBR 05.11.2026](<../../meetings/[2026-11-05 14-00] PBR Возвраты_summary.md>), тема 1).

## Открытые вопросы

#### 1. В какой момент строка позиции заказа делится на две — при создании заявки на возврат или при приёмке изделий на складе или в магазине?

**Кому:** System Architect (Леша Осипенко)

Позиция заказа получает «Заявка на возврат» при создании заявки, поэтому возвращаемые и оставшиеся единицы расходятся по статусу уже в этот момент. Предлагаемый ответ: вторая строка создаётся при создании заявки на возврат.

#### 2. Сливается ли отделённая строка с исходной, если заявку отменили или изделия не приняли?

**Кому:** System Architect (Леша Осипенко)

При отмене заявки позиция заказа возвращается в статус, который был до заявки ([return-status_state.md](../diagrams/state/return-status_state.md)). Если строки сливаются, какой статус получает объединённая строка? Если строки не сливаются, какой статус остаётся у отделённой строки?

#### 3. Верно ли деление строки в примере с тремя футболками?

**Кому:** System Architect (Леша Осипенко)

В позиции 3 белые футболки, клиент вернул 2. Исходная строка остаётся с количеством 1, новая строка с количеством 2 получает «Частичный возврат». Клиент возвращает последнюю футболку: единица добавляется в ту же новую строку, строка получает «Возврат», исходная строка удаляется.

#### 4. Хранятся ли единицы одной позиции с разными статусами возврата в отдельных строках?

**Кому:** System Architect (Леша Осипенко)

Пример: одну футболку уже приняли, вторую по новой заявке ещё не сдали. Предлагаемый ответ: по строке на каждый статус.

#### 5. Копируются ли цены позиции в новую строку без изменений при делении?

**Кому:** System Architect (Леша Осипенко)

В `cms_order_positions` цены `price` и `price_before_discount` хранятся на одно изделие. Скидки `discount_bonus`, `discount_promo`, `discount_manual`, `discount_rounding`, `discount_sum`, списанные баллы `spend_bonus` и итог `sum` хранятся на всю позицию ([orders-er.md](../../../../knowledge/12storeez-master-web/database/orders-er.md)).

#### 6. Делятся ли скидки, списанные баллы и `sum` между строками пропорционально количеству, и в какую строку уходит остаток от округления?

**Кому:** System Architect (Леша Осипенко)

Пример: скидка 1000 ₽ на позицию из 3 изделий не делится на равные суммы в рублях.

#### 7. Нужно ли при делении строки распределять по позициям начисленные баллы?

**Кому:** System Architect (Леша Осипенко)

Начисленные баллы хранятся только на заказ — `cms_orders.given_bonus`. Поле `given_bonus` у позиции не заполняется.
