# ADR-RET-055: Текст инструкции «Что дальше» хранится на стороне сайта в способе возврата, в существующих полях способа доставки

## Контекст

В карточке возврата есть блок «Что дальше». Его текст зависит от способа возврата: курьер, ПВЗ СДЭК,
5Post, магазин, Почта России (`FR-48`). Нужно решить, где этот текст хранится и где его настраивают:
на стороне сайта или в сервисе логистики.

Способы возврата по городам в первой итерации ведутся на стороне сайта (`ADR-RET-060`, `FR-23`).
У способов доставки в админке сайта уже есть поля для комментариев, которые показываются клиенту.
Способы возврата хранятся там же, где способы доставки, и отличаются от них признаком.

## Решение

1. Текст инструкции «Что дальше» задаётся отдельно для каждого способа возврата в админке сайта, в
   настройках способа возврата.
2. Новые поля под тексты способа возврата не заводятся. Используются существующие текстовые поля
   способа доставки (поля комментариев): способы возврата и способы доставки — разные записи, поэтому
   значения не пересекаются. Какое поле под какой текст, определяет разработка.

## Последствия

### Положительные

- Текст инструкции меняется в админке без доработки кода и без участия сервиса логистики.
- Не появляется новое поле в модели данных способов доставки.

### Отрицательные и риски

- Одни и те же поля имеют разный смысл для доставки и для возврата. Без явного признака записи можно
  перепутать, где текст для доставки, а где для возврата.
- Если способы возврата позже перейдут в сервис логистики (сценарий 2 `ADR-RET-060`), тексты
  придётся переносить.

## Рассмотренные альтернативы

### Тексты инструкций в сервисе логистики

- **Результат:** отклонена для первой итерации.
- **Причина:** на стороне сайта, по аналогии с заказами, сделать быстрее.

### Отдельное поле для инструкции возврата

- **Результат:** отклонена.
- **Причина:** значения для доставки и возврата не пересекаются, новое поле не нужно.

## Условия пересмотра

- Способы возврата переносятся в сервис логистики (сценарий 2 `ADR-RET-060`).
- Для одного способа возврата понадобится больше одного текста (например, разные тексты для сайта и
  мобильного приложения или по статусам возврата).
