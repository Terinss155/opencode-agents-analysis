# ADR-RET-117: При полном возврате статус заказа не меняется, Mindbox определяет возврат по статусам строк

| Поле | Значение |
|---|---|
| **Статус** | Предложено |
| **Дата решения** | не определена |
| **Владелец решения** | System Analyst — Катя Лемешева; предложила Project Manager — Катя Тихомирова; подтверждение — менеджер Mindbox (Ирина Васильева) |
| **Область** | Интеграция |
| **Версия** | v1 |

## Контекст

При возврате статус заказа на сайте не меняется: «Заказ выполнен» или «Заказ выдан» остаётся, возврат виден по статусам позиций (`ADR-RET-039`). Для частичного возврата Mindbox смотрит на статусы строк. Для полного возврата менеджер Mindbox 23.11.2026 требовала передавать статус заказа «возврат» ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), вопрос 2).

На встрече 24.11.2026 менеджер Mindbox назвала два метода: смену статуса всего заказа и изменение заказа по позициям (`00:36:57–00:37:25`, `00:41:46`). В том же блоке она повторила требование 23.11: не может быть, чтобы все позиции ушли в возврат, а заказ остался выполненным, — если все позиции возвращены, заказ должен быть в статусе возврата (`00:36:57–00:37:25`). Затем она сказала, что сайт, наверное, будет передавать статусы построчно, и «если мы увидим, что у нас все заказы перешли в статус возврата, у нас он будет возвращён» (`00:38:12`); трактовка — речь о строках заказа. Определять частичный или полный возврат по статусам строк для Mindbox не дополнительная нагрузка (`00:43:14`, подтверждено участником встречи). Оговорка менеджера Mindbox: на сайте заказ останется выполненным, от этого может страдать аналитика (`00:40:05–00:40:58`).

После встречи менеджер Mindbox подтвердила, что `Website.UpdateOrderv2` принимает весь заказ по позициям ([переписка 24.11.2026](<../../sources/answers/[2026-11-24] Переписка Васильева, Лемешева (метод Website.UpdateOrderv2 по позициям).md>)). Явного согласия на вариант без смены статуса заказа при полном возврате не было (подтверждено участником встречи).

## Решение

Предлагается при полном возврате статус заказа не менять и метод смены статуса всего заказа не вызывать. Сайт передаёт в Mindbox изменение заказа по позициям с полным составом заказа: все строки — со статусом возврата, в доп. поле `orderStatus` остаётся «Заказ выполнен» или «Заказ выдан». В каждом изменении сайт передаёт полный состав заказа (`00:41:37`); статус заказа уходит символьным кодом в доп. поле `orderStatus` ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), факт 2). Полный возврат Mindbox определяет сам по статусам строк (`00:43:14–00:43:40`, `00:44:00`, `00:44:36`).

## Последствия

### Положительные

- Одна схема обмена для частичного и полного возврата, статусная модель заказа не меняется (`ADR-RET-039`; `00:35:57`).
- Реализация проще: сайт отправляет весь заказ, нужен только правильный маппинг статусов строк (`00:44:00`, `00:44:36`).

### Отрицательные и риски

- Не подтверждено, что Mindbox примет без ошибки заказ, у которого все строки в возврате, а `orderStatus` — «Заказ выполнен» ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), вопрос 2.1). Если не примет — нужна новая версия `ADR-RET-039`.
- Выполненный заказ участвует в аналитике, оборотах и начислении баллов (`00:37:49`). Менеджер Mindbox предупредила, что от неизменного статуса заказа может страдать аналитика (`00:40:58`).
- Если Mindbox ориентируется на статус заказа, по полностью возвращённому заказу со статусом «Заказ выполнен» он может начислить баллы за покупку (`00:37:49`).
- Правило балльного счёта «для каких статусов заказов не возвращать баллы» менеджер Mindbox описала через статусы заказа — полный и частичный возврат, отмена (`00:13:25–00:13:59`). Как оно сработает, если статус заказа не меняется, не подтверждено; коды строк возврата, которые передаёт сайт, в исключения не входят ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), факт 9, решение 17).
- Письма и сценарии Mindbox, завязанные на возвратные статусы заказа, перестанут срабатывать ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), вопрос 16).

## Рассмотренные альтернативы

### Менять статус заказа при полном возврате или передавать в Mindbox статус возврата заказа

- **Результат:** не отклонена; выбор зависит от ответа Mindbox ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), вопрос 2.2).
- **Причина рассмотрения:** Mindbox проверяет согласованность статуса заказа и строк ([разбор встречи 23.11.2026](<../../meetings/[2026-11-23 12-00] Обсуждение по возвратам бб (предрасчет и обновление заказа)_summary.md>), тема 3).

## Открытые вопросы

- Определяет ли Mindbox полный возврат по статусам строк, если все строки в `401`, а в `orderStatus` остаётся «Заказ выполнен», и примет ли такой заказ без ошибки? **Кому:** менеджер Mindbox (Ирина Васильева). Схема по ситуациям — [mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), «Сообщения с оставшимися вопросами».

## Условия пересмотра

- Mindbox ответит, что для полного возврата нужен статус заказа «возврат».
