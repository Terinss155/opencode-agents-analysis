# ADR-RET-068: Проверка доступности способов возврата в админке — в существующей проверке доставки с отметкой «для возврата»

## Контекст

В админке сайта есть функция, где Дружба по городу проверяет доступность служб доставки. Для
возвратов Дружбе нужно так же проверять, какие способы возврата доступны для города или адреса, и
видеть даты и интервалы, на которые можно назначить курьера.

## Решение

1. В админке сайта Дружба проверяет доступность способов возврата, дат и интервалов курьера по
   городу или адресу.
2. Новый экран не делается: в существующую проверку доставки добавляется отметка «для возврата».
3. Работа оформляется отдельной задачей.

## Последствия

### Положительные

- Дружба отвечает клиенту о доступных способах возврата без оформления заявки.
- Не нужен новый экран в админке.

### Отрицательные и риски

- Админка сайта для возвратов шире, чем только просмотр (`ADR-RET-059`).
- Даты и интервалы зависят от сервиса логистики (`ADR-RET-057`): при его недоступности проверка
  ничего не покажет.

## Рассмотренные альтернативы

### Отдельный экран проверки возвратов

- **Результат:** отклонена в предложении.
- **Причина:** существующая проверка доставки закрывает задачу отметкой.

## Условия пересмотра

- Список заказов и связанные функции уберут из админки сайта в RetailCRM.
