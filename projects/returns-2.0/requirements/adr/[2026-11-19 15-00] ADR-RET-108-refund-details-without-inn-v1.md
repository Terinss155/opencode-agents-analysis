# ADR-RET-108: Поле ИНН убирается из формы банковских реквизитов на сайте и в МП уже на этапе 0

| Поле | Значение |
|---|---|
| **Статус** | Принято |
| **Дата решения** | 19.11.2026 |
| **Владелец решения** | Head of PMO — Светлана Варцаба; предложение — System Analyst — Катя Лемешева |
| **Область** | Продукт / Данные |
| **Версия** | v1 |

## Контекст

В форме банковских реквизитов на сайте и в МП есть поле ИНН банка. По задачам этапа 0 оно уже необязательное. Бухгалтерия подтвердила, что ИНН банка в возврате указывать не обязательно; в обмене с 1С `bank_inn` передаётся пустой строкой ([stage-0-bank-details_questions.md](../questions/stage-0-bank-details_questions.md), вопрос 1С-9).

## Решение

Поле ИНН убирается из формы банковских реквизитов на сайте и в МП сейчас, на этапе 0, а не в «Возвратах 2.0». Клиент ИНН больше не заполняет.

## Последствия

### Положительные

- Форма реквизитов короче на одно поле, которое никому не нужно.

### Отрицательные и риски

- Нужны доработки сайта, iOS и Android; релиз МП идёт по своему циклу.
- Будет ли удаление поля блокером для отказа от бумажного заявления (`ADR-RET-107`), не решено: Product Manager предположила, что не будет.

## Рассмотренные альтернативы

### Оставить ИНН необязательным до «Возвратов 2.0»

- **Результат:** отклонена.
- **Причина:** поле не нужно, убрать его можно сразу.

## Условия пересмотра

- Бухгалтерия или банк начинают требовать ИНН банка для возврата.

## Открытые вопросы

1. Блокирует ли удаление поля ИНН отказ от бумажного заявления, если релиз МП не успевает к 03.12.2026?
