# ADR-RET-012: Раздельное отображение одинаковых позиций товара

## Контекст

При оформлении заявки на возврат клиенту необходимо выбрать товары, которые он хочет вернуть. Возник вопрос о том, как отображать в интерфейсе ситуацию, когда клиент купил несколько одинаковых единиц одного и того же товара (количество больше одной штуки в заказе).

## Решение

В интерфейсе оформления возврата каждая единица товара должна выводиться отдельно (отдельной карточкой/строкой друг под другом). Клиент выбирает не количество возвращаемого товара через счетчик (плюс/минус), а отмечает галочками каждую конкретную единицу товара, которую планирует вернуть.

## Последствия

### Положительные
- Более прозрачный и понятный для клиента пользовательский опыт при частичном возврате одинаковых позиций.
- Упрощается логика работы с причинами возврата: для каждой единицы товара можно указать свою уникальную причину (например, одна футболка не подошла по размеру, а вторая пришла с браком).

### Отрицательные и риски
- Если в заказе большое количество одинаковых мелких товаров, список на возврат визуально сильно увеличится, что может потребовать дополнительного скролла.

## Условия пересмотра

- Подтверждено, что для заказов с большим количеством одинаковых позиций построчный список
  единиц существенно ухудшает UX и требует возврата к модели «счётчик количества».
- Согласована модель `available_return_quantity`, при которой отображение каждой единицы
  отдельной строкой становится технически избыточным.
