## Контекст

В v1 (`ADR-RET-010`) решили управлять доступностью способов возврата по Geo ID. Место настройки
оставили открытым: админка сайта или сервис логистики.

Сейчас сайт и логистика интегрированы только по двум методам: список ПВЗ и даты/интервалы курьеров.
Способы доставки прямого потока хранятся на сайте. Рассматривались два сценария:

1. Способы возврата хранятся на сайте (по аналогии со способами доставки), используется текущая
   интеграция с логистикой.
2. Логистика отдаёт способы возврата по Geo ID, а также все ПВЗ, даты и интервалы. Доработок
   больше.

Более ранний материал (17.09.2026): Product Manager возражала против ведения способов возврата
вручную на стороне сайта. Её аргументы: логики, связанной с возвратами, на сайте нет; правки пришлось
бы вносить через разработчиков по каждой ТК; ПВЗ часто открываются и закрываются. System Analyst BTS
отметила, что вариант через логистику требует больших доработок, и взялась исследовать оба варианта.

## Решение

Предложение Head of PMO (24.09.2026), окончательный выбор — после оценки обоих сценариев до
18.10.2026 (так зафиксировано в `user-story.md` от 01.10.2026: п. 7 и TODO по Geo ID).

В первой итерации логистика подключается в текущем виде, без глубоких доработок. Используется уже
существующая интеграция, а способы возврата по Geo ID ведутся на стороне сайта (сценарий 1).

Сценарий 2 (способы возврата из логистики) переносится на следующую итерацию.

Объём работ по обоим сценариям оценивают к 18.10.2026: System Analyst BTS — по логистике, команда
сайта — по сайту и фронту.

## Последствия

### Положительные

- Первая итерация не зависит от доработок сервиса логистики.
- Используются уже работающие методы получения ПВЗ и интервалов курьеров.

### Отрицательные и риски

- Справочник способов возврата по Geo ID на сайте придётся перенести в логистику в следующей итерации.
- Сайт получает от логистики все ПВЗ и не проверяет, принимают ли они возвраты (`OQ-38`).
- Срок 18.10.2026 участники назвали напряжённым: для оценки сайту нужна помощь команды.
- Product Manager 17.09.2026 возражала против ручного ведения способов на сайте. Её возражение
  предложением 24.09.2026 явно не снято.

## Рассмотренные альтернативы

### Способы возврата по Geo ID из сервиса логистики в первой итерации (сценарий 2)

- **Результат:** отложена до следующей итерации.
- **Причина:** нужно больше доработок; в первой итерации решено не идти в глубокие переработки.

## Условия пересмотра

- Оценка к 18.10.2026 показывает, что сценарий 1 не меньше сценария 2 по сроку или объёму.
- Начинается проработка следующей итерации с интеграцией логистики.
