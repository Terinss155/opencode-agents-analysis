# ADR-RET-072: Клиентские возвраты из Калининграда и области принимает калининградский магазин

| Поле | Значение |
|---|---|
| **Статус** | Принято |
| **Дата решения** | 15.10.2026 |
| **Владелец решения** | Acting Head of Transport Logistics — Артем Лисин; участники: Project Manager — Катя Тихомирова, Head of PMO — Светлана Варцаба |
| **Область** | Бизнес-процесс / Логистика |
| **Версия** | v1 |

## Контекст

Для Калининграда и области из способов возврата доступна только Почта России, без интеграции и
отслеживания (`RULE-15`, `ADR-RET-011`). В Калининграде открылся магазин. Открыт вопрос, добавлять
ли для Калининграда возврат через магазин (`OQ-42`).

## Решение

1. Клиентские возвраты из Калининграда и Калининградской области принимает магазин в Калининграде.
2. Запуск — в ноябре 2026 года, после того как магазин включится в работу (по просьбе розницы).

## Последствия

### Положительные

- Для Калининграда есть возврат с подтверждённой приёмкой, без Почты России.
- Запуск в ноябре раньше запуска нового процесса возвратов.

### Отрицательные и риски

- Не определено, остаётся ли Почта России способом возврата для Калининграда и в каком порядке
  показывать способы.
- Нужно включить магазин в список магазинов, принимающих возвраты (`ADR-RET-035`).

## Рассмотренные альтернативы

### Только Почта России

- **Результат:** отклонена.
- **Причина:** решение логистики; магазин в Калининграде уже открыт.

## Условия пересмотра

- Розница не сможет принимать возвраты в калининградском магазине.
