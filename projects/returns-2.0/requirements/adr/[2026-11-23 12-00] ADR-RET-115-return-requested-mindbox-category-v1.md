# ADR-RET-115: Статус строки «Заявка на возврат» в Mindbox не относится к категориям «Возврат» и «Отмена»

| Поле | Значение |
|---|---|

| **Дата решения** | 23.11.2026 |
| **Владелец решения** | System Analyst — Катя Лемешева; подтверждено: менеджер Mindbox — Ирина Васильева, System Analyst команды BTS — Елена Васильева |
| **Область** | Интеграция |
| **Версия** | v1 |

## Контекст

Когда клиент или Дружба создаёт заявку на возврат, строка позиции исходного заказа с изделиями заявки получает статус «Заявка на возврат» (`ADR-RET-112`; [схема статусов v4](../diagrams/state/return-status-v4_state.md), правило O1). Если заявку или позицию в ней отменили, строка возвращается в прежний статус (правило O2; `ADR-RET-039`, `ADR-RET-073`). Баллы возвращаются только при «Возврат принят» (`ADR-RET-110`, решение 17).

В Mindbox у каждого статуса строки есть категория: «Оформлена», «Оплачена», «Доставлена», «Возврат», «Отменена». Когда строка переходит в статус категории «Возврат» или «Отмена», Mindbox сразу возвращает списанные баллы, и вернуть строку в другой статус после этого нельзя. Статус Mindbox для строки сайт берёт из маппинга `cms_mb_statuses_map` по паре «статус заказа + статус позиции»; пар со статусом «Заявка на возврат» в маппинге нет ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), факты 3, 4, 8).

По словам менеджера Mindbox, Mindbox записывает тот статус строки, который прислал сайт. Из статуса, который не относится к категориям «Возврат» и «Отмена», строку можно вернуть в прежний статус при отмене заявки. После фактического возврата сайт должен прислать статус возврата, иначе строка останется в промежуточном статусе.

## Решение

Если строка с позицией в статусе «Заявка на возврат» передаётся в Mindbox, её статус Mindbox не относится к категориям «Возврат» и «Отмена».

## Последствия

### Положительные

- Отмена заявки не ломает заказ в Mindbox: строку можно вернуть в прежний статус.
- Баллы не возвращаются раньше приёмки изделий — так же, как в статусной модели (`ADR-RET-110`, решение 17).

### Отрицательные и риски

- Для статуса «Заявка на возврат» нужны строки `cms_mb_statuses_map`. Без них строка уйдёт в Mindbox со статусом `101` «Позиция на резерве» категории «Оформлена»: баллы не вернутся, но статус по смыслу неверный.
- Какой код Mindbox ставить — исходный код строки или новый статус Mindbox, — не определено ([mindbox-exchange_questions.md](../questions/mindbox-exchange_questions.md), вопрос 6). Новый статус заводит менеджер Mindbox по названию, идентификатору и бизнес-смыслу; точную категорию менеджер Mindbox предложила согласовать отдельно.
- При отмене заявки или позиции в ней сайт должен передать строку в Mindbox с прежним статусом, а после «Возврат принят» — обязательно со статусом возврата. Если статус возврата не отправить, строка останется в промежуточном статусе, и баллы клиенту не вернутся.
- Смена статуса позиции из 1С сейчас не отправляет заказ в Mindbox, если не меняется статус заказа (там же, факт 17): переход в «Заявка на возврат», обратно и в «Возврат» сайт должен отправлять в Mindbox сам.

## Рассмотренные альтернативы

### Отнести «Заявка на возврат» к категории «Возврат» или «Отмена»

- **Результат:** отклонена.
- **Причина:** Mindbox вернёт баллы при создании заявки, а при отмене заявки строку нельзя будет вернуть в прежний статус.

## Условия пересмотра

- Бизнес решит возвращать баллы при создании заявки, а не при «Возврат принят».
- Mindbox разрешит переводить строку из статуса категории «Возврат» или «Отмена» в другой статус.
