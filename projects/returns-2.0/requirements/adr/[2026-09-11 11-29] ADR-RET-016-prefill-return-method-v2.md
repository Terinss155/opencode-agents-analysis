# ADR-RET-016: Обязательный предвыбор способа возврата на основе исходного заказа

## Контекст

В версии v1 (`ADR-RET-008`) при недоступности исходного способа доставки для возврата или при
исходном ПВЗ, не принимающем возвраты, предзаполнение не производилось и клиент выбирал способ сам.

На обсуждении макетов 11.09.2026 выяснилось, что набор полей формы (в том числе перечень точек)
привязан к выбранному способу: без предвыбранного способа форме нечего показать. Тот же вопрос
возникает при смене клиентом города в процессе оформления.

## Решение

Система предвыбирает способ и адрес возврата по следующим правилам:
1. Если заказ был доставлен в ПВЗ и этот конкретный пункт принимает возвраты — данный ПВЗ предвыбирается по умолчанию.
2. Если заказ был доставлен курьером — по умолчанию предвыбирается возврат курьером на тот же адрес.
3. Если способ доставки доступен для возврата, но исходный ПВЗ не принимает возвраты, способ
   предвыбирается, а поля точки остаются пустыми — клиент заполняет их сам.
4. Если способ доставки недоступен для возврата в городе (например, Яндекс) или не совпадает ни с
   одним способом возврата, предвыбирается первый по приоритету доступный способ (сейчас — курьер;
   приоритет определяет бизнес).

Предвыбор способа обязателен всегда: от него зависит, какие поля видит клиент. До подтверждения
возврата клиент может перевыбрать город и способ; в созданной заявке они не меняются (отмена и
создание новой — `ADR-RET-001`).

## Последствия

### Положительные

- Форма всегда находится в определённом состоянии: набор полей и перечень точек известны сразу.
- Сохраняются преимущества v1: клиенту предлагается знакомый способ из исходного заказа.

### Отрицательные и риски

- Требуется справочник приоритета способов возврата, который ведёт бизнес.
- Клиенту может быть предвыбран способ, не связанный с исходным заказом (первый по приоритету),
  и ему придётся сменить его вручную.
- Сохраняется зависимость от признака «ПВЗ принимает возвраты» для конкретного пункта.

## Рассмотренные альтернативы

### Не предвыбирать способ, если исходный недоступен для возврата (решение v1)

- **Результат:** отклонена.
- **Причина:** поля формы и перечень точек привязаны к способу; без предвыбора форма не определена.

### Всегда предвыбирать самый дешёвый для компании способ (например, ПВЗ)

- **Результат:** отклонена (сохранено из v1).
- **Причина:** клиенту, заказавшему курьером, удобнее вернуть товар тоже курьером.

## Условия пересмотра

- Логистика подтверждает или опровергает возможность получить признак «ПВЗ принимает возвраты» для конкретного пункта на момент оформления возврата.
- Бизнес не утверждает приоритет способов возврата для правила п. 4.
