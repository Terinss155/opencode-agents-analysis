# ADR-RET-095: Состав электронного заявления на возврат согласован с Отделом дружбы

| Поле | Значение |
|---|---|
| **Статус** | Принято |

| **Владелец решения** | Head of Customer Service — Ольга Соколова; согласовала System Analyst — Катя Лемешева; на встрече 15.10.2026 подтвердили Head of PMO — Светлана Варцаба, Project Manager — Катя Тихомирова |
| **Область** | Бизнес-процесс / Данные |
| **Версия** | v1 |

## Контекст

Электронное заявление заменяет бумажное (`RULE-02`) и формируется по запросу из данных заявки (`ADR-RET-024`). Скачивание заявления выделено в отдельную историю US3.1 (`ADR-RET-058`). Состав данных заявления в требованиях не был определён: в User Story и SRS указано только, что заявление формируется из данных заявки.

Бумажное заявление сейчас заполняют и обрабатывают сотрудники Отдела дружбы.

Отчества нет в данных заказа. Форма банковских реквизитов содержит ФИО держателя счёта (`FR-37`).

## Решение

1. Электронное заявление содержит:

   | Блок | Данные | Условие |
   |---|---|---|
   | Заявление | Номер возврата — тот же номер, что отображается в ЛК клиента | Всегда |
   | Заявление | Дата оформления заявления | Всегда |
   | Данные заявителя | ФИО | Всегда; отчество — при наличии |
   | Данные заявителя | Номер телефона | Всегда |
   | Данные заказа | Номер заказа | Всегда |
   | Данные заказа | Дата получения заказа клиентом | Всегда |
   | Данные заказа | Способ возврата изделий — курьер, СДЭК, 5POST и другие | Всегда |
   | Данные заказа | Способ возврата денежных средств — на исходный способ оплаты или по банковским реквизитам | Всегда |
   | Возвращаемые изделия | Артикул, наименование, размер, количество | По каждому изделию |
   | Возвращаемые изделия | Стоимость за единицу изделия | По каждому изделию |
   | Возвращаемые изделия | Стоимость за единицу изделия с учётом применённых баллов — рядом с обычной стоимостью | По каждому изделию |
   | Возвращаемые изделия | Причина возврата | По каждому изделию |
   | Итог | Итоговая сумма к возврату денежных средств — с учётом скидок и списанных баллов | Всегда |
   | Банковские реквизиты | ФИО держателя счёта, название банка, БИК банка, номер лицевого счёта | Только если клиент заполнил реквизиты при оформлении возврата на сайте или в МП |

2. Отчество заявителя при возврате на исходный способ онлайн-оплаты необязательно и может отсутствовать в заявлении. При возврате по банковским реквизитам отчество обязательно и запрашивается у клиента при заполнении реквизитов на сайте или в МП.

3. Состав заявления согласует Отдел дружбы; отдельного согласования с бухгалтерией не требуется.

## Последствия

### Положительные

- Команды сайта, МП и 1С получают единый перечень данных заявления для формирования PDF.
- Состав определил отдел, сотрудники которого работают с заявлениями.
- Номер возврата в заявлении совпадает с номером в ЛК: клиент, Дружба и бухгалтерия находят возврат по одному номеру.

### Отрицательные и риски

- Стоимость за единицу с учётом баллов требует баллов, списанных на каждую единицу изделия; расчёт баллов к возврату не утверждён (`ADR-RET-092`, предложено).
- Правило расчёта итоговой суммы к возврату с учётом скидок и баллов не определено.
- Для воспроизведения заявления на момент оформления нужно хранить все данные из перечня, включая реквизиты (`NFR-01`, `ADR-RET-024`).
- Заявление содержит персональные и платёжные данные: ФИО, телефон, реквизиты счёта.
- Бухгалтерия состав не согласовывала; если ей нужны другие данные для выплаты, состав придётся менять.

## Рассмотренные альтернативы

### Дополнительно согласовать состав заявления с бухгалтерией

- **Результат:** отклонена.
- **Причина:** заявления заполняют сотрудники Отдела дружбы, их согласования достаточно.

### Отчество заявителя обязательно во всех заявлениях

- **Результат:** отклонена.
- **Причина:** отчества нет в данных заказа; при возврате на исходный способ онлайн-оплаты его негде взять без дополнительного запроса у клиента.

## Условия пересмотра

- Бухгалтерия или юристы требуют в заявлении данные, которых нет в перечне.
- Утверждённый расчёт баллов к возврату не даёт баллы на единицу изделия.
- Отчество появляется в данных заказа или профиле клиента как обязательное поле.

## Открытые вопросы

1. Где формируется заявление — на сайте или в 1С с передачей ссылки (`ADR-RET-058`, `ADR-RET-024`)?
