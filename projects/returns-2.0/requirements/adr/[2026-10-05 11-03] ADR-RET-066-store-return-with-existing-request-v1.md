# ADR-RET-066: Если у клиента есть заявка другим способом, магазин меняет способ в этой заявке, а не создаёт новую

| Поле | Значение |
|---|---|

| **Дата решения** | Не определена |
| **Владелец решения** | Project Manager — Катя Тихомирова (предложение); участники: Product Manager — Катя Филатова, System Analyst — Катя Лемешева |
| **Область** | Бизнес-процесс / Розница |

## Контекст

Клиент оформил заявку, например на курьера, не отменил её и пришёл сдать изделие в магазин. Ранее
договорились, что такая заявка не блокирует возврат в магазине: клиента не просят её отменять.
Тогда на одну единицу оказываются две заявки: старая остаётся и «протухает» сама, магазин создаёт
новую.

Возврат в магазине обрабатывается в АРМ маркетинга (1С КА) (`ADR-RET-051`). Если клиент пришёл
без заявки, заявка создаётся автоматически.

## Решение

Если у клиента есть действующая заявка на возвращаемую единицу, магазин не создаёт новую заявку, а
меняет в существующей способ возврата на «магазин» и принимает возврат по ней.

Предложение нужно подтвердить; условие — у магазина есть доступ ко всем заявкам, включая курьерские.

## Последствия

### Положительные

- На одну единицу не появляется две заявки.
- Не нужно ждать, пока старая заявка «протухнет».

### Отрицательные и риски

- В АРМ магазина нужна операция смены способа в заявке с синхронизацией в RetailCRM и на сайт.
  Клиенту редактирование по-прежнему недоступно (`ADR-RET-001`).
- Если по старой заявке уже вызван курьер, его вызов нужно отменить. Как — не определено.

## Рассмотренные альтернативы

### Магазин создаёт новую заявку, старая остаётся и закрывается сама

- **Результат:** отклонена в предложении.
- **Причина:** на одну единицу копятся дубли заявок.

### Магазин отменяет старую заявку и создаёт новую

- **Результат:** отклонена в предложении.
- **Причина:** лишнее действие; результат тот же, что при смене способа.

## Условия пересмотра

- В АРМ маркетинга (1С КА) не будет доступа к заявкам, оформленным другими способами.
- Смену способа в заявке не поддержит обмен с RetailCRM.
