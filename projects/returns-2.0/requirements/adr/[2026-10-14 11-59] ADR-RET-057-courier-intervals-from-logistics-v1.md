# ADR-RET-057: Даты и интервалы курьера для возврата сайт получает от сервиса логистики; если их нет, курьер для адреса недоступен

| Поле | Значение |
|---|---|
| **Статус** | Принято |
| **Дата решения** | 14.10.2026 |
| **Владелец решения** | Project Manager — Катя Тихомирова; участники: System Architect — Леша Осипенко, System Analyst — Катя Лемешева |
| **Область** | Интеграция |
| **Версия** | v1 |

## Контекст

При возврате курьером клиент выбирает дату и интервал приезда (`FR-13`). Даты и интервалы
показываются только после ввода адреса (`FR-42`): сайт передаёт адрес в логистику и только после
ответа узнаёт, есть ли свободные интервалы.

Сервис логистики уже интегрирован со СДЭК и получает от него даты и интервалы. Для доставки есть
задача на интеграцию сайта с этим методом сервиса логистики, команда её уже оценила.

## Решение

1. Даты и интервалы приезда курьера для возврата сайт получает от сервиса логистики, а сервис
   логистики — от СДЭК. Используется тот же метод, что для доставки.
2. Сайт сам даты и интервалы не рассчитывает.
3. Если для введённого адреса сервис логистики не вернул ни одной даты или интервала, вызвать курьера
   на этот адрес нельзя. Клиенту показывается сообщение, что курьер для возврата на этот адрес
   недоступен, и предложение выбрать другой способ возврата. Сообщение нужно добавить в макеты.

## Последствия

### Положительные

- Даты совпадают с реальными возможностями ТК.
- Интеграция повторяет уже оценённую задачу для доставки.

### Отрицательные и риски

- Доступность курьера клиент узнаёт только после ввода адреса.
- При недоступности сервиса логистики возврат курьером оформить нельзя.

## Рассмотренные альтернативы

### Сайт сам определяет даты и интервалы

- **Результат:** отклонена.
- **Причина:** сервис логистики уже получает даты и интервалы от СДЭК.

### Создавать заявку без даты, если интервалы не пришли

- **Результат:** отклонена.
- **Причина:** на встрече решили, что без интервалов курьер на этот адрес недоступен.

## Условия пересмотра

- Курьерский возврат будет выполнять другая ТК, не СДЭК.
- Сервис логистики перестанет отдавать даты и интервалы курьера.
