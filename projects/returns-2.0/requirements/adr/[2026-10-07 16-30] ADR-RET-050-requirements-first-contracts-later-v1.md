# ADR-RET-050: Аналитик описывает сценарии и критерии приёмки, техническую реализацию прорабатывает разработка, контракты между командами — вторым этапом

## Контекст

Команда сайта оценила первую историю — создание заявки на возврат: в ней появляются новые таблицы и
весь новый функционал. Разработка готова брать задачи в спринт с 19.10.2026, цель — запуск до
предновогодней распродажи (около 15.12.2026).

System Analyst одна описывает сайт и МП, уходит в контракты и модель данных и не успевает.

## Решение

1. System Analyst описывает сценарии пользователя, бизнес-требования и критерии приёмки — User Story,
   при необходимости Use Case. Модель данных и контракты до уровня реализации не детализируются.
2. Модель данных прорабатывается совместно с разработкой. Контракты между сайтом и мобильным
   приложением разработчики согласуют сами в ходе работы, как при запуске нового чекаута.
3. Контракты на стыках команд (сайт — 1С, сайт — RetailCRM) готовятся вторым этапом, после сбора
   требований, по принципу contract first. Стыки заранее перечисляет 1C Solution Architect.
4. User Story по первой части — создание заявки — для команды сайта описаны к пятнице 16.10.2026.

## Последствия

### Положительные

- Разработка может начать 19.10.2026.
- Аналитик не дублирует работу разработчиков по технической реализации.

### Отрицательные и риски

- Технические решения принимаются в ходе разработки, их нужно согласовывать встречами
  с аналитиком.
- Разработчики сайта и МП могут по-разному реализовать одну логику, если не договорятся о контракте.

## Рассмотренные альтернативы

### Полное описание контрактов и модели данных аналитиком до разработки

- **Результат:** отклонена.
- **Причина:** ресурс анализа ограничен, разработка не стартует 19.10.2026.

### Сначала полностью описать бэк монолита, потом мобильное приложение

- **Результат:** не выбрана.
- **Причина:** предложение Project Manager; итог встречи — описывать по User Story.

## Условия пересмотра

- Разработка не может работать по User Story без технических спецификаций.
- В команду анализа добавят второго аналитика.
