# ADR-RET-024: Электронное заявление не хранится, формируется по запросу из данных заявки

## Контекст

После отказа от бумажного заявления нужно было решить, кто и где хранит электронные заявления.
Product Manager отметила, что этот вопрос не был решён.

## Решение

Электронное заявление (PDF) как файл не хранится. Его формируют по запросу из данных, собранных
на сайте: клиент — в ЛК, уполномоченный сотрудник — для своей задачи.

Хранятся поля, которые клиент вводит в ЛК. В какой системе и в какой структуре их хранить, этим
решением не определено — это задача команды сайта.

## Последствия

### Положительные

- Нет хранилища PDF-файлов и их синхронизации между системами.
- Заявление всегда соответствует актуальным данным заявки.

### Отрицательные и риски

- Нужно хранить исходные данные и их версии, чтобы воспроизвести заявление на момент
  оформления (`NFR-01`).
- Место хранения полей не определено.

## Рассмотренные альтернативы

### Хранить сформированные PDF-заявления

- **Результат:** отклонена.
- **Причина:** файлы не нужны: заявление формируется, только если его запросили.

## Условия пересмотра

- Бухгалтерия, юристы или регулятор требуют хранить заявление именно как неизменяемый файл.
