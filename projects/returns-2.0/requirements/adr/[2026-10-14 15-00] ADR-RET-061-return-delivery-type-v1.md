# ADR-RET-061: Для возвратов заводится отдельный тип доставки со своими ФИАС, а не признак возврата у существующего типа

## Контекст

Даты и интервалы курьера логистика отдаёт по коду типа доставки (`ADR-RET-060`). Для курьерских
типов доставки прямого потока ФИАС населённых пунктов заливаются отдельно. Для курьерского
возврата СДЭК ФИАС не залиты.

У СДЭК для доставки четыре типа доставки, для возврата — один. Логисты по типу доставки решают,
кто и куда едет; у возврата своя логика: курьер не доставляет, а забирает. Гео возврата может
отличаться от гео доставки.

По словам Product Manager, тип доставки для возврата уже создавали при прошлой доработке возвратов
(«по-моему»); не подтверждено.

## Решение

1. Для возврата заводится отдельный тип доставки (новый слаг) во всех системах: 1С, логистика,
   сайт и «РТС» (так в транскрибации).
2. Для курьерского возврата в этот тип отдельно заливаются ФИАС населённых пунктов, где курьер
   забирает возврат.
3. Новой таблицы на сайте нет. ТК и тип доставки для возврата заводятся новыми записями в
   `cms_delivery_tk`, населённые пункты для них — в `cms_delivery_city` с `tk_id` возвратных ТК; ФИАС
   хранится в `cms_delivery_city.geo_id`. Если у логистики для возврата свой набор населённых пунктов, для него готовится свой CSV с
   ФИАС; таблица та же.
4. Запросы в логистику за датами и интервалами для возврата идут по возвратным ТК.

## Последствия

### Положительные

- Гео и настройки возврата не зависят от типов доставки прямого потока.
- Логисты различают доставку и забор возврата по типу доставки.

### Отрицательные и риски

- Нужно завести тип во всех системах и поддерживать отдельный список ФИАС.
- Не подтверждено, создан ли тип доставки возврата ранее.

## Рассмотренные альтернативы

### Признак возврата у существующего типа доставки СДЭК

- **Результат:** отклонена.
- **Причина:** гео и логика возврата отличаются от доставки; у СДЭК четыре типа доставки на
  доставку и один на возврат.

## Условия пересмотра

- Логистика начнёт сама отдавать способы возврата по населённому пункту (сценарий 2 из
  `ADR-RET-060`).
