# ADR-RET-056: «Смотреть на карте» в карточке возврата в мобильном приложении открывает внешнее приложение карт, встроенной карты нет

## Контекст

В макетах карточки возврата для ПВЗ СДЭК, 5Post и магазина есть кнопка «Смотреть на карте».
По ней клиент только смотрит, где находится выбранная точка передачи. Сменить точку в карточке
нельзя (`ADR-RET-001`).

Встроенную карту в мобильном приложении уже убирали из-за проблем с её реализацией и так и не
переделали. В бронировании осталась кнопка, которая открывает любое внешнее приложение карт,
установленное у клиента. В карточке заказа такой кнопки нет.

## Решение

1. В мобильном приложении кнопка «Смотреть на карте» в карточке уже созданной заявки на возврат
   открывает внешнее приложение карт, установленное у клиента (например, Яндекс Карты). Используется
   существующий механизм из раздела «Бронирования».
2. Кнопка нужна только для того, чтобы посмотреть, где находится выбранная точка передачи, и
   построить до неё маршрут. Выбрать или изменить точку через неё нельзя.
3. Встроенная карта в карточке возврата в рамках проекта не делается.

Как кнопка работает на сайте, этим решением не определено. На встрече предлагали использовать
методы карты выбора ПВЗ СДЭК и 5Post из оформления доставки с фильтром по признаку возврата.

## Последствия

### Положительные

- Не нужно делать новую встроенную карту и исправлять старые проблемы с картами в МП.
- Механизм уже есть в приложении (бронирование).

### Отрицательные и риски

- Клиент уходит из приложения в другое.
- Что делает кнопка, если у клиента нет приложения карт, не определено.

## Рассмотренные альтернативы

### Встроенная карта (Яндекс) в карточке возврата

- **Результат:** отклонена в рамках проекта.
- **Причина:** с картами в МП были проблемы, их убрали и не переделали; переделка не входит в
  объём возвратов и займёт больше времени.

## Условия пересмотра

- В мобильном приложении снова появится встроенная карта.
- В карточке возврата понадобится выбирать или менять точку передачи.
