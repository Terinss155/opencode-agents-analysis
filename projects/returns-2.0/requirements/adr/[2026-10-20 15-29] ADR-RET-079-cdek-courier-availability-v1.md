# ADR-RET-079: Курьерский возврат СДЭК доступен только в населённых пунктах с офисом СДЭК

| Поле | Значение |

| **Дата решения** | 20.10.2026 |
| **Владелец решения** | Product Manager — Катя Филатова; участники: System Analyst (BTS) — Елена Васильева, Acting Head of Transport Logistics — Артём Лисин |
| **Область** | Продукт / Логистика / Данные |

## Контекст

Курьеры СДЭК работают только в населённых пунктах, где есть офис СДЭК. Офис — пункт выдачи с
сотрудником; постаматы к офисам не относятся, и сайт их не принимает. Часть офисов СДЭК работает
только на выдачу посылок. Работают ли курьеры во всех населённых пунктах с офисом или только там,
где офис принимает посылки, не известно.

Для курьерского возврата населённые пункты заливаются в отдельный возвратный тип доставки по ФИАС
(`ADR-RET-061`).

## Решение

1. Способ «Курьер» СДЭК для возврата показывается только в населённых пунктах, где есть офис СДЭК.
   Где офиса нет, способ не показывается.
2. Список ФИАС этих населённых пунктов берётся из ApiShip и заливается в возвратный тип доставки
   курьера СДЭК.

## Последствия

### Положительные

- Клиент не оформит курьерский возврат туда, куда курьер СДЭК не приедет.

### Отрицательные и риски

- Список ФИАС нужно поддерживать в актуальном виде: офисы СДЭК открываются и закрываются.
- Пока не известно, учитывать ли офисы только на выдачу; от этого зависит состав списка.

## Рассмотренные альтернативы

Альтернативы на встрече не обсуждались.

## Условия пересмотра

- СДЭК подтвердит, что курьеры работают только там, где офис принимает посылки, — список сужается.
- СДЭК начнёт отдавать зону работы курьеров по API.
