## Порядок выкатки

1. Баг номера карты — сделан (ECOMDEV-2530).
2. ECOMDEV-2526 + ECOMDEV-2649 + ECOMDEV-2532 — одним релизом. Фронт и бэкенд монолита собираются одним пайплайном и выкладываются одной командой; включение трёх задач в один релиз — по процессу команды.
3. iOS и Android — после релиза п. 2: текущий бэкенд требует ИНН и номер карты при любом счёте.
4. Признаки в 1С (ECOMDEV-2651) — после ECOMDEV-2649, после ответа на 1С-12. Признак подтверждения для возврата через RetailCRM — после ответа на Р-7, при приёме возврата из RetailCRM.
