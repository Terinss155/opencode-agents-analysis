## Порядок выкатки

1. Баг номера карты — сделан (ECOMDEV-2530).
2. ECOMDEV-2649 + ECOMDEV-2532 — одновременно; ECOMDEV-2526 пп. 1–2 (сайт) — с ними или после.
3. ECOMDEV-2526 пп. 3–4 (МП) — одним релизом.
4. iOS, Android — после ECOMDEV-2526 пп. 3–4: текущий бэк требует ИНН и номер карты при любом счёте.
5. Признаки в 1С (ECOMDEV-2651, раздел 3); признак подтверждения для возврата через RetailCRM — после ответа на Р-7.
