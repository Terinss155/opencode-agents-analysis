# Элементы экранов оформления возврата: мобильное приложение, MVP

Сценарии, вызовы методов и логика — в [SRS МП MVP](../srs/srs-mobile-mvp.md) (US 1.1–1.5). Здесь — состав экранов и ограничения полей. Тексты на макетах — пример: описания способов, тексты «Возврат средств» и подсказки к причинам приходят с сервера.

Макеты: [`sources/mockups/v2 Создание возврата/MVP/`](<../../sources/mockups/v2 Создание возврата/MVP/>). Экран созданного возврата и экран «Возврат заказов» — в [спецификации экранов](../screen-spec/screen-spec.md).

Порядок экранов:

```mermaid
flowchart LR
    A["Экран заказа"] --> B["1. Выберите изделия"]
    B --> C["2. Причина возврата"]
    C --> D["3. Оформление возврата"]
    D --> E["4. Шторка выбора города"]
    D --> F["5. Банковские реквизиты"]
    D --> G["6. Выбор пункта или магазина"]
    D --> H["7. Отдел дружбы с клиентами"]
    D --> I["8. Заявка уже у нас"]
    I --> J["Экран возврата"]
```

## Экран 1. Выберите изделия

Макеты: `2`, `3`. US 1.2, шаги 1–5.

| Элемент | Свойства | Действие |
|---|---|---|
| **1.1. Кнопка «Назад»** | • Тип: кнопка-иконка<br>• Отображается: всегда | Закрыть экран, вернуться на экран заказа |
| **1.2. Заголовок** | • Тип: текст<br>• По умолчанию: «Выберите изделия»<br>• Если выбрано N ≥ 1 изделий — «Выберите изделия · N» | — |
| **1.3. Предупреждение о комплектации** | • Тип: текст<br>• Отображается: всегда<br>• По умолчанию: «Пожалуйста, возвращайте изделие в полной комплектации (включая пояса, съемные броши и кофры)» | — |
| **1.4. Строка изделия** | • Тип: карточка<br>• Отображается: для позиций с `items[].can_be_returned = true`; позиции с `false` не отображаются<br>• Одна строка на изделие: строк столько, сколько `items[].available_return_quantity`<br>• Кофр или подарок, если он отдельная позиция заказа, — отдельной строкой<br>• Состав: фото, цена, наименование, артикул, цвет и размер — из ответа метода `GET /получить карточку заказа` | Нажатие на строку переключает чекбокс 1.5 |
| **1.5. Чекбокс изделия** | • Тип: чекбокс<br>• По умолчанию: не отмечен<br>• Кофр или подарок при выборе основного изделия не отмечается автоматически | Отметить или снять изделие; пересчитать N в 1.2 и состояние 1.7 |
| **1.6. Цена** | • Формат: `12 980 ₽`<br>• Если есть цена до скидки — цена со скидкой красным и цена до скидки зачёркнутой<br>• Артикул — «Арт. XXXXXX», цвет и размер — «[маркер] Цвет · Размер» | — |
| **1.7. Кнопка «Указать причину возврата»** | • Тип: основная кнопка, закреплена внизу<br>• По умолчанию: неактивна<br>• Активна, если отмечено хотя бы одно изделие | Запросить справочник причин и открыть экран 2 |
