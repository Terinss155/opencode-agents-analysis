# ECOMDEV-2359: [B] Добавить признак приёма возвратов

## Цель

Добавить магазинам признак «Принимает возвраты», чтобы метод списка магазинов для возврата показывал клиенту только магазины, которые принимают возвраты. Признак настраивается в админке.

## Описание реализации

Что требуется изменить:

1. Создать поле `cms_catalog_stock.for_returns` — раздел 1.
2. Вывести признак в форму редактирования магазина в админке — раздел 2.

Вне этой задачи:
* новые таблицы возврата (`cms_returns`, `cms_return_positions`, `cms_return_statuses` и др.) — задача на модель данных;
* отбор магазинов по `cms_catalog_stock.for_returns` — задачи на метод списка магазинов для возврата (`[B][Mobile API]`, `[B][Web]`);
* населённые пункты, где работают службы возврата, — отдельные возвратные службы и типы доставки в `cms_delivery_tk` и их города в `cms_delivery_city` (`ADR-RET-061`);
* признак приёма возвратов у пункта выдачи — приходит от логистики в данных пункта (`is_return_available`, задача логистики TNT-2712).

---

#### 1. Создать новые данные БД

Поле создаётся по аналогии с существующим `cms_catalog_stock.for_reservation`.

| Таблица | Поле | Тип | NULL | По умолчанию | Комментарий |
|---|---|---|---|---|---|
| `cms_catalog_stock` | `for_returns` | `tinyint(1)` | Нет | `0` | Магазин принимает возвраты |

По умолчанию `0`: магазин принимает возвраты только после явного включения.

{red}(Начальные значения: какие магазины отмечаются при выкатке — миграцией по списку или вручную в админке.)

#### 2. Вывести признак в админку

| Раздел админки | Поле формы | Тип | Значение для новой записи | Сохраняется в |
|---|---|---|---|---|
| Магазины и склады — форма редактирования магазина | «Принимает возвраты» | Чекбокс | Не отмечен | `cms_catalog_stock.for_returns` |

### Ошибки

Новых методов API нет — раздел не заполняется.

## Тестирование

**Предусловия**
- Миграция применена.

**Критерии приёмки**
- В `cms_catalog_stock` есть поле `for_returns` (`tinyint(1)`, NOT NULL, по умолчанию `0`); у существующих записей значение `0`.
- Чекбокс «Принимает возвраты» сохраняется и отображается в форме редактирования магазина.
- Откат миграции удаляет поле.
