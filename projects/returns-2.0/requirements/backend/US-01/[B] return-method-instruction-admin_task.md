# [B] Админка. Настройки возврата. Инструкция «Что дальше» для способа возврата

## Цель

Дать возможность заводить в админке для каждого способа возврата текст инструкции, что клиенту делать после создания заявки. Текст показывается в блоке «Что дальше» карточки созданного возврата на сайте и в МП.

**Админка**
- Раздел «Настройки возврата» → список способов возврата → редактирование способа

## Описание реализации

Что требуется изменить:

1. Создать поле `cms_return_method.instruction` — раздел 1.
2. Добавить поле «Инструкция «Что дальше»» в форму редактирования способа возврата — раздел 2.
3. Описать правила сохранения поля — раздел 3.

Вне этой задачи: вывод инструкции в карточке созданного возврата (метод карточки возврата на сайте, `[B][Mobile API]` и `[B][Mobile API][Gate]`) — отдельные задачи, ссылки в «Связях».

---

#### 1. Создать новые данные БД

Создать поле `cms_return_method.instruction` по аналогии с существующим `cms_return_method.description`.

| Атрибут | Значение |
|---|---|
| Поле | `instruction` |
| Таблица | `cms_return_method` |
| Тип | `text` |
| Nullable | Да |
| Default | `NULL` |
| Назначение | Текст инструкции «Что дальше» для карточки созданного возврата |

#### 2. Поля формы админки

Форма редактирования способа возврата. Существующие поля не меняются (AS-IS: «Название», «Описание», «Включен на сайте», «Включен на МП»).

| Поле формы | Тип | Обязательность | Ограничение | Сохраняется в |
|---|---|---|---|---|
| Инструкция «Что дальше» | Многострочный текст | Нет | Не более 1480 символов {red}(длина — по аналогии с «Описанием», подтвердить) | `cms_return_method.instruction` |

Поле располагается после поля «Описание».

#### 3. Логика сохранения

**Проверки выполняются последовательно — от первого пункта к последнему.**

1. **Обработка значения**
   1. Пробелы в начале и конце текста удаляются.
   2. Пустая строка сохраняется как `NULL`.
2. **Проверка длины**
   1. Длина текста не больше ограничения из раздела 2 → значение сохраняется в `cms_return_method.instruction`.
   2. Иначе → способ не сохраняется, под полем выводится ошибка валидации формы, как у поля «Описание».

> **AS-IS:** далее применяется существующая логика сохранения способа возврата (название, описание, флаги включения на сайте и в МП). Она не изменяется в рамках данной задачи.

## Тестирование

**Предусловия**
- Пользователь админки с доступом к разделу «Настройки возврата».

**Критерии приёмки**
- В форме редактирования каждого способа возврата есть поле «Инструкция «Что дальше»».
- Введённый текст сохраняется в `cms_return_method.instruction` и отображается в форме при повторном открытии.
- Очищенное поле сохраняется как `NULL`.
- Текст длиннее ограничения не сохраняется, выводится ошибка валидации.
- Сохранение инструкции не меняет «Название», «Описание» и флаги включения способа.
