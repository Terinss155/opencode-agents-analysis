После стендапа System Analyst, System Architect и Backend Developer обсудили деление строки позиции заказа. System Architect считает, что после отмены строки нужно объединять обратно в базе, а не только при выдаче данных. System Analyst пересказала, что нужно на этапе 0; Backend Developer назвала задачу простой и ждёт описание. System Analyst предложила не добиваться от Дружбы заполнения реквизитов в RetailCRM: подтверждением служит файл у бухгалтерии. Перед встречей с Mindbox System Analyst хочет выяснить, что изменится у Mindbox из-за новой статусной модели.
