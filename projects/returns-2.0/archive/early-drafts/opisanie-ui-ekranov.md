# Описание UI экранов

1. Пользователь нажимает "Оформить возврат"
2. Открывается экран с товарами которые можно вернуть (не забыть что могут быть в будущем позиции которые выкупить нельзя) - *при открытии страницы заказа уже получили данные*
3. Выбирается товар по позиции (может быть несколько штук по одному barcode)
4. Пользователь нажимает "Указать причину возврата"
5. Открывается экран с первым товаром и выбором причины возврата (двухэтапный выбор причины) - *запрашиваются причины*
6. Пользователь выбрал причину для каждого товара и нажимает "Продолжить"
7. Система должна определить город:
   1. Если не определила, то пользователь попадает на страницу с выбором города (страны) - вызовы информации по стране/городу
   2. Если определили, то
8. Пользователь определился с городом
9. Система открывает экран со способами возвратов - *как определять какой способ возврата доступен этому городу?  какой способ возврата мы ставим в приоритете, то есть после открытия экрана?*

#### Разветвление

Курьер

1. Если заказ оплачивался курьеру (картой либо наличными), то показываем доп. поле для заполнения реквизитов - *сейчас уже есть данный признак*
2. Пользователь заполняет улицу, дом, кв *- есть методы, инфу получаем от геосервиса*
