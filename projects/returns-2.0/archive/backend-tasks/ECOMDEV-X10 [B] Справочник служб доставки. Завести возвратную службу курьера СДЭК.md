# ECOMDEV-X10: [B] Справочник служб доставки. Завести возвратную службу курьера СДЭК

## Цель

Завести на сайте возвратную службу курьера СДЭК — со своим кодом типа доставки и своим списком городов. По ней сайт определяет, доступен ли возврат курьером в городе, и запрашивает у логистики даты забора ([ADR-0006](https://wiki.yandex.ru/teams/web-development/arxitektura/adr/adr-0006-stepen-integracii-servisa-logistiki-na-sa/)).

Курьер СДЭК на возврат работает в тех же городах, где есть ПВЗ СДЭК, принимающие возврат.

Эндпоинты:
- Web: `GET /api/orders/{order_id}/return-method-list`, `GET /delivery/delivery/intervals`
- Mobile API: метод способов возврата МП и метод интервалов МП — по той же логике

## Описание реализации

Предусловие: тип доставки `sdek-courier-vzt` «Курьер СДЭК (возврат)» заведён в 1С, RetailCRM и сервисе логистики заявкой в техподдержку {red}(номер заявки). В сервисе логистики тип возвратный и привязан к ТК СДЭК с включённой интеграцией интервалов (TNT-2837).

1. Завести в `cms_delivery_tk` службу «СДЭК курьер (возврат)» на тестовом и продовом контурах. Новый способ доставки в `cms_delivery_types` не заводится: используется существующий тип «курьер».

   | Поле | Значение |
   |---|---|
   | `title` | СДЭК курьер (возврат) |
   | `name` | СДЭК |
   | `title_mobile` | СДЭК курьер (возврат) |
   | `type` | 1 (курьер) |
   | `slug` | `sdek-courier-vzt` |
   | `slug_tk` | номер в словаре RetailCRM {red}(из заявки в техподдержку) |
   | `state` | 0 (выключено) — на тесте и на проде |
   | `cost` | 0 |
   | остальные поля | как у службы «СДЭК_790р_РФ» (`cms_delivery_tk.id = 322` на staging) |

   Выключенная служба не выводится в корзине и при оформлении заказа.
2. Загрузить города службы в `cms_delivery_city` (ФИАС в `geo_id`, `tk_id` возвратной службы) из файла BTS: ФИАС городов, где есть ПВЗ СДЭК, принимающие возврат (провайдер `sdek-pvz`).
3. Создать параметр админки с кодом типа доставки возвратного курьера:

   | Атрибут | Значение |
   |---|---|
   | `alias` | `return_courier_delivery_type_code` |
   | `value` | `sdek-courier-vzt` |
   | `title` | Код типа доставки возвратного курьера |
   | `description` | Служба, по городам которой доступен возврат курьером и по коду которой запрашиваются даты забора |

4. Способы возврата для города: способ «Курьер» доступен, если город, регион или страна возврата есть в городах службы с кодом из параметра. Обычные курьерские службы для возврата не учитываются. Значение «Отображения» службы при этом не проверяется.
5. Метод интервалов: код из параметра принимается, даже если служба выключена. Сейчас метод отвечает 400 на код службы с выключенным «Отображением». Для остальных кодов проверка не меняется.

Вне этой задачи:
- заведение типа доставки `sdek-courier-vzt` в 1С, RetailCRM и сервисе логистики — заявкой в техподдержку; новая ТК в 1С или существующая ТК СДЭК — на решение 1С и логистики;
- обновление городов возвратных служб вебхуком `POST /api/v1/delivery/webhooks/city-carriers-coverage` по признаку `has_return_points` у `sdek-pvz`, включая добавление новых городов, — отдельная задача на доработку вебхука;
- пункты выдачи СДЭК и 5Post на возврат запрашиваются у логистики по обычным кодам `sdek-pvz` и `5post` с фильтром `is_return_available` (ADR-0006);
- служба «СДЭК ПВЗ (возврат)» (`sdek-pvz-vzt`) хранит города возврата через ПВЗ СДЭК; в запросах к логистике её код не передаётся.

## Критерии приёмки

- Служба «СДЭК курьер (возврат)» заведена с кодом типа доставки `sdek-courier-vzt`, который совпадает с кодом в 1С, RetailCRM и сервисе логистики; служба выключена.
- Города службы загружены из файла BTS и совпадают с городами, где есть ПВЗ СДЭК, принимающие возврат.
- В корзине и при оформлении заказа на сайте и в МП служба не отображается.
- Способ возврата «Курьер» отдаётся только в городах возвратной службы. В городе, где есть обычная курьерская служба, но нет возвратной, способа «Курьер» нет.
- Метод интервалов с кодом `sdek-courier-vzt` возвращает даты и интервалы, а не 400.
- Если в параметре админки указать другой код, способ «Курьер» и интервалы определяются по службе с этим кодом.
