# Первичные транскрибации

В этой папке хранятся неизменённые первичные транскрибации интервью, встреч и рабочих сессий.

## Правила хранения

- Текст сказанного не исправляется и не дополняется выводами аналитика.
- Редакторские пометки, резюме и перечни решений оформляются отдельными файлами вне этой папки.
- Для каждого файла сохраняются дата встречи, тема и источник записи, если они известны.
- Рекомендуемое имя: `ГГГГ-ММ-ДД_<тема>_transcription.<расширение>`.
- ADR и требования ссылаются на транскрибацию относительной markdown-ссылкой, но не заменяют её.
- Если решение изменилось, первичная транскрибация не изменяется; актуальность решения ведётся
  через статус соответствующего ADR.
