- **Елена Васильева** · 23.10.2026, ~11:00 — ответ в ветке

  > Катя, привет! :12-heart: 
  >
  > Добавляет гео сервис, она отдаётся в ответе метода grpc geo/SuggestAddress, когда вызывается подсказка по дому. Делали в задаче https://tracker.yandex.ru/TNT-1500
  > Всегда для подсказки по дому. Из ТЗ: Добавить логику формирования подсказки с признаком "manual:" для подсказки по дому, где "ручная" подсказка должна всегда приходить последним элементом в списке подсказок
  > Приходит только для дома, для улицы не приходит
  > Да, приходит в ответе grpc geo/SuggestAddress для дома
  > ```
  >      {
  >          "id": "manual: Россия, Таганрог, Петровская, 1",
  >          "suggest": "Россия, Таганрог, 1",
  >          "title": "1",
  >          "subtitle": "Россия, Таганрог"
  >      }
  > ```
