> как называется параметр адреса отправки и тот же ли у него формат — одна строка, как у delivery_address?
> Это будет новое поле или новый метод интервалов для возвратов с таким же полем?

- **Елена Васильева** · 22.10.2026, 15:19 — ответ в ветке

  > Для прямого потока
  >
  > метод в Логистике rpc logistics.winner.Intervals
  > пример запроса
  > ```
  > {
  > "delivery_type_code": "string", // код типа доставки
  > "timezone": "UTC+07:00",
  > "order_type": 0,
  > "delivery_address": "string" // адрес доставки - строка с адресом клиента, куда доставить заказ
  > }
  > ```
  > писала об этом здесь https://mattermost.12stz.com/12storeez/pl/nz3a6r13npnyigout3zk8h47mo
  > Для возвратного потока
  >
  > метод в Логистике rpc logistics.winner.Intervals - планирую, что будет тот же метод
  > пример запроса
  > ```
  > {
  > "delivery_type_code": "string", // код типа доставки
  > "timezone": "UTC+07:00",
  > "is_return": true,
  > "sending_address": "string" // адрес отправки - строка с адресом клиента, откуда забрать посылку
  > }
  > ```
  > то есть в тот же метод планируем добавить два новых параметра "is_return" и "sending_address"
  > предварительно такие доработки, если команда не зарубит
  > и если вы согласитесь для возвратов адрес отправки передавать, а не код города. писала в этом треде - если нужно, то давай поставим встречу, чтобы точно договориться, что адрес отправки сможете нам отправлять
