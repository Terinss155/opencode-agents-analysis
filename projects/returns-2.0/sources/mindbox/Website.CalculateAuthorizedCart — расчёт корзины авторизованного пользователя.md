# Website.CalculateAuthorizedCart — расчёт корзины авторизованного пользователя

Документация Mindbox, получена 17.11.2026.

Ссылка: https://12storeez.mindbox.ru/campaigns/operations/303/help#JSON-SpecRequestDescription

## Предварительный расчет заказа

Сервис используется в корзине интернет-магазина или на кассе оффлайн-магазина. В сервис передается полный состав заказа со всеми внешними акциями, которые нужно к нему применить.

В ответ возвращается информация о заказе с пересчитанными ценами (с учетом активных в данный момент промоакций, промокодов и других скидок), и детальной информации о всех скидках, запрошенных покупателем.

В процессе расчета скидок Mindbox может разделить одну линию на несколько. Подробнее о распределении скидок можно почитать тут. В этом случае в ответе вернется несколько линий с одинаковым lineId, по которому клиент может понять, какая именно позиция была разделена. Клиент должен корректно обработать такую ситуацию и каждой новой линии присвоить свой уникальный идентификатор для последующих запросов.

## Запрос

```
POST https://api.b.mindbox.ru/v3/operations/sync?endpointId={Идентификатор точки интеграции}&operation=Website.CalculateAuthorizedCart&deviceUUID={UUID устройства}

Content-Type: application/json; charset=utf-8
Accept: application/json
Authorization: SecretKey {Секретный ключ}
User-Agent: {User-Agent устройства клиента}
X-Customer-IP: {IP адрес клиента}
```
