# DEVIOS-2694: [iOS] Изменить логику отображения интервалов доставки

Ссылка: https://tracker.yandex.ru/DEVIOS-2694

## Цель

Сейчас метод `POST /api/v1/delivery/intervals` отдает в МП ручные интервалы, требуется сделать вывод интервалов от СДЕК.

Курьерской службе (КС) СДЕК важно, чтобы при загрузке интервалов был передан адрес, на который будет осуществлена доставка клиенту, поэтому загрузка интервалов возможна только если адрес указан. В случае отсутствия переданного адреса КС СДЕК вернет ошибку в ответе.

## Реализация

При получении `show_intervals: true` для способа доставки МП должно загрузить интервалы доставки ( `POST /api/v1/delivery/intervals`) , только если указан (выбран) адрес доставки.

Данная логика распространяется на все способы доставки, независимо от того, является ли ТК/КС СДЕК или другая.

{% cut "Обратная соместимость" %}

- если адрес не передан, метод `POST /api/v1/delivery/intervals` возвращает ручные интервалы // подойдёт для старых версий МП
- если адрес передан: при включенной интеграции - интервалы от cdek; при выключенной - ручные // подойдёт для новых версий МП

{% endcut %}

{% cut "Требования к UI" %}

Старый чекаут:

1. Блок с интервалами скрыт пока не введен (заполнены все обязательные поля ввода адреса) или не выбран адрес доставки
2. В момент, когда пользователь ввел валидный адрес доставки, система выполняет запрос на получение интервалов доставки `POST /api/v1/delivery/intervals` (если `show_intervals: true`), кнопка основного действия "продолжить" заблокирована
3. Пока идет загрузка интервалов на экране выбора адреса доставки отображается [loading state ](https://www.figma.com/design/IGfD5jnGsQpA1635iCFDqJ/01-%E2%9C%A6-Base-UI-Components?node-id=13835-69799&t=fMpHTUnzKT6gg7bP-4)
4. После получение интервалов кнопка основного действия "продолжить" становится активна

Новый чекаут:

1. Блок с интервалами скрыт пока не введен (заполнены все обязательные поля ввода адреса) или не выбран адрес доставки
2. В момент, когда пользователь ввел валидный адрес доставки, система выполняет запрос на сохранение выбранного адреса, после обработки апдейт флагов вызывает метод получения интервалов доставки `POST /api/v1/delivery/intervals` (если `show_intervals: true`)
3. Пока идет загрузка интервалов на экране выбора адреса доставки отображается состояние загрузки на кнопке основного действия (по возвращении на основной экран чекаута чтобы не было дополнительных лоадеров)
