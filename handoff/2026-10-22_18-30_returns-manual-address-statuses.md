## Принятые решения
- Для ручного адреса даты запрашиваются; пришли — «Заявка на возврат принята», не пришли — Дружбе в «Возврат ожидает обработки»; причина «проверить адрес» в RetailCRM — только когда даты не получены — встреча 22.10 + пользователь, `ADR-RET-089`.
- В запросе интервалов только полный адрес и для заказа, и для возврата; код города не передаём; параметры (предварительно) `delivery_address` / `sending_address` + `is_return` — встреча 22.10 + переписка Лены 14:41, `ADR-RET-090`.
- Статус «Возврат ожидает обработки» — отдельный от статуса заказа; статуса утери нет, есть признак утери; позиции при утере — «Принято»; деньги до поступления изделий → «Возврат завершён», приёмка не меняет; в «Возврат принят» — из «Заявка на возврат принята», «Подтверждение возврата», «Возврат отправлен» — `ADR-RET-091`.
- Частичная сдача по заявке в свой магазин: несданные позиции «Отменено» — `ADR-RET-088`.
