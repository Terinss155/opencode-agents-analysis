## Принятые решения
- Рабочее название статуса после валидации сайта — «Заявка на проверке в 1С»; окончательно — на созвоне (вопрос 1) — пользователь, 13.11.
- Магазин отменяет заявку в свой магазин в 1С КА, где принимает изделия — пользователь, 13.11 (`ADR-RET-051`).
- Утеря возврата возможна из «Заявка на возврат принята», «Подтверждение возврата», «Возврат отправлен»; позиция заказа получает «Частичный возврат» или «Возврат», т. к. заявка переходит в «Возврат принят» — пользователь, 13.11.
- Статус заказа при возврате не меняется, заказ остаётся завершённым — пользователь, 13.11 (`ADR-RET-039`).
- Строка позиции заказа делится сразу при создании заявки — мнение пользователя, 13.11; Лёше ещё не отправлено.
- В вики-копиях нет столбца «Основание»; таблицы — в разметке Яндекс Вики — пользователь, 13.11.
