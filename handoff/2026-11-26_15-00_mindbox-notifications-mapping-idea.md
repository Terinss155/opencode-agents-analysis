## Где остановились
Ждём ответ Лизы Кузнецовой на уточняющие вопросы. Ничего по уведомлениям и вопросу 6 в файлы требований не вносилось — по решению пользователя.

**Ключевая находка (из ответа Лизы 25.11, 18:48):** письма Mindbox привязаны к кодам статуса строки: `401` — «Заявка на возврат»; `411` (принята на складе), `504` (поступил в магазин), `505` (принят и внесён в базу) — свои письма; `322` — «Запрос реквизитов». `returnTrackNumber`, `returncertificate` в письмах не используются. Про письма по статусам заказа Лиза не сказала. Сейчас код строки меняется, потому что 1С меняет статус заказа (пара «статус заказа + статус позиции» в `cms_mb_statuses_map`). В новом процессе статус заказа не меняется → строка возврата всегда `401` и только при приёмке: письмо «Заявка на возврат» придёт после приёмки, письма `411`/`504`/`505` не уйдут.

**Идея пользователя (не согласовано, записать после ответа Лизы в вопрос 17 `mindbox-exchange_questions.md`):** добавить в маппинг статусов для Mindbox статус заявки на возврат: «статус заказа + статус позиции + статус заявки» → код Mindbox, коды писем прежние. Что учесть (из анализа сессии):
1. До приёмки нельзя слать коды категории «Возврат» (`401`, `411`, `504`, `505`, `322`): Mindbox сразу вернёт баллы, строку нельзя перевести обратно (решение 17, `ADR-RET-115`). Нужен новый промежуточный код (вариант «б» вопроса 6), письмо «Заявка на возврат» CRM перенастраивает на него.
2. Плюс: старый процесс продолжает слать `401` при заявке из ЛК — письма старого процесса не ломаются.
3. Переходы внутри категории «Возврат» (`401` → `505` → `411`) сейчас происходят — подтвердить у Ирины.
4. «Возврат принят» один для склада и магазина — чтобы различать `411`/`504`, нужен ещё признак (способ возврата?). Пользователь упоминала «дату» — уточнить, для чего.
5. Строка = изделия одной заявки; несколько заявок по позиции → несколько строк со своими кодами (решение 15). Отменённые изделия — прежний код.
6. Больше отправок: каждая смена статуса заявки, меняющая код, → `Website.UpdateOrderv2`. Фиксация баллов совпадает с первым кодом категории «Возврат» («Возврат принят»).
7. Где хранить третий ключ — решает разработка (Оля).

Пример маппинга (иллюстрация): «Заявка создана…Возврат отправлен» → новый код (не «Возврат»/«Отмена») — письмо «Заявка на возврат»; «Возврат отменён» → `311`/`302`; «Возврат принят» склад → `411`, магазин → `504`; «Возврат завершён» → `505`?
