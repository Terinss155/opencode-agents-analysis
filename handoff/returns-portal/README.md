# Идея: интерактивный портал «Возвраты 2.0» для SA и разработки

Дата: 17.11.2026 · Статус: MVP собран, отложен — доступ не выдан

## Зачем

Общая база знаний по всему проекту для системного аналитика (Катя Лемешева) и разработчика (Оля Свистунова) по одной ссылке: решения, открытые вопросы с ответами, расхождения между требованиями и задачами, источники, история изменений. Каждая сторона добавляет сведения прямо на странице; информация перестаёт копиться только в локальных папках.

## Что сделано

- Страница на claude.ai (Artifact) с общей базой (`db`), авторами записей (`user`), загрузкой файлов (`assets`), выгрузкой Markdown / JSON для Claude Code (`downloads`).
- Разделы: обзор, бизнес-логика, статусная модель, API, модель данных, задачи; интеграции 1С, RetailCRM, Mindbox, логистика. Реестры: вопросы, расхождения, журнал решений, источники, все записи. Поиск, фильтры, связи между записями, лента изменений.
- Типы записей и статусы: новые сведения, предложение, вопрос, решение, расхождение, задача, источник.
- Заполнен раздел «Интеграция с 1С»: 12 решений, 14 вопросов, 2 расхождения с ECOMDEV-2587, 1 сведения, 4 задачи, 7 источников.

## Почему остановились

Опубликовано от общей учётной записи Claude Code `claude_transformation-it@12storeez.com`: страница приватная, открывается только под ней. Под `e.lemesheva@12storeez.com` — «не найдено». Выдать доступ можно только владельцем через «Поделиться» на странице; из Claude Code права не меняются.

Ссылка (владелец — общая учётная запись): https://claude.ai/artifact/4QM4h8hXyFF4cfDoQyWmLk

## Как продолжить

1. Войти на claude.ai под общей учётной записью (окно инкогнито), открыть ссылку, в «Поделиться» добавить себя и Олю с правом редактирования; или
2. Переключить Claude Code на свою учётную запись (`/login`), опубликовать `portal.html` заново с capabilities `{"db": {}, "user": {"scopes": ["profile"]}, "assets": {"upload": "interact"}, "downloads": true}`, перенести записи из `seed/` пакетом (ArtifactData `batch` с `file_path` на каждый файл: коллекции `entries`, `blocks`, `changes`), затем в «Поделиться» добавить Олю и общую учётную запись с правом редактирования — чтобы Claude Code под общей учётной записью тоже читал и пополнял портал.

После доступа: проверить совместную работу (Оля отвечает на вопрос), затем переносить остальные разделы — сначала проверка дублей и актуальности материалов, только действующие версии ADR.
