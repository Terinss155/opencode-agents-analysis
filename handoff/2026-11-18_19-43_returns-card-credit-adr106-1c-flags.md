## Принятые решения
- Номер карты запрашивается и обязателен (16 цифр), только если номер счёта начинается с «30232810». Для других счетов поле скрыто, номер карты не передаётся и не хранится. Сайт и МП определяют по началу номера, бэкенд проверяет при создании заявки. Решение Тихомировой, 18.11.2026, `ADR-RET-106`.
- Правило карты распространяется на этап 0 — пользователь, 18.11.2026 (в артефакты ещё не внесено).
- Чекбокс подтверждения реквизитов добавляется и в SRS сайта — пользователь, 18.11.2026.
- Обмен с 1С, согласовано с Мезиновой:
  - названия признаков остаются, тип boolean;
  - `is_bank_details_confirmed` передаётся в `customer`;
  - `bank_inn` передаётся пустой строкой;
  - `money` не меняется;
  - условия `true` / `false` для `is_refund_to_original_payment_method` — по списку способов оплаты в переписке от 16.11.
