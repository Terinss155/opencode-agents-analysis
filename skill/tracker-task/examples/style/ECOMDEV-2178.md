# ECOMDEV-2178: [F] Бронирование. Посмотреть список магазинов с наличием товара по выбранному городу

> Офлайн-копия задачи С. Щербатых, снята 17.11.2026 (статус в Трекере — «Можно тестировать», описание может меняться). Оригинал: https://tracker.yandex.ru/ECOMDEV-2178. Правила копирования — [README](./README.md).
> Образец варианта А `templates/frontend.md` (есть SRS и макеты).

## Цель

По клику на блок "Наличие и бронь в магазинах" показать пользователю список магазинов его города с наличием товара и дать опционально отфильтровать список по размеру / возможности бронирования

При возникновении каких-либо вопросов ориентироваться на реализацию в МП

**Необходимо:**

1. В карточке товара по клику на блок "Наличие и бронь в магазинах":

   1. Вызвать `GET product/product/product-cities/{product_id}` ( ECOMDEV-1508 ) с `geo_id` из профиля пользователя, без фильтра по размеру, `reservation=0` для получения списка городов и магазинов
   2. Вызвать `GET product/product/{id}/store-availability`: geo_id (id города из профиля пользователя), reservation=0 (по умолчанию показываем пользователю размеры, доступные в магазинах независимо от возможности бронирования) для получения доступных размеров для фильтра "Выберите размер" https://tracker.yandex.ru/ECOMDEV-1497

2. Открыть боковую панель "Выберите магазин". Для каждого магазина показать: название (`store`), адрес (`address`), доступные размеры из `stocks[]` (`size_id`)

3. Если `data.message` не пуст - показать информационное сообщение над списком

4. На экране есть отдельный фильтр "Выберите размер" (по умолчанию "Не выбран"). По клику открыть попап выбора размера со всеми размерами, доступными в городе (`store-availability?geo_id=...&reservation=0`, без `delivery_tk_id`).

5. После выбора размера в этом попапе - обновить значение в фильтре "Выберите размер" и отфильтровать список магазинов до тех, где этот размер есть в наличии. Выбранный размер передаётся как предвыбранный в попап выбора размера в карточке магазина (US3).

6. Пользователь может включить переключатель "Можно забронировать"  повторяет product-cities с reservation=1/0 - список фильтруется до магазинов с `reservation=true`. Фильтр по размеру и переключатель комбинируются друг с другом.

7. По клику на магазин  открыть его карточку данными из того же объекта (`address`, `route`, `schedule`, `number`, `lat`/`lng`, `tk_id`, `reservation`)

### **Текстовки для пустых состояний**

++Кейс 1++: заходим в раздел, выбран город, где нет магазина или в моменте скрыли остатки, то есть массив {red}(`data.`)`cities`пустой в ответе метода `GET product/product/product-cities/{product_id}`, размер не выбран (barcode не передан)
текст: "**В выбранном городе изделия нет в наличии. Оформите онлайн-заказ с доставкой или измените город**"

++Кейс 2++: заходим в раздел, размер выбран (barcode передан), не активирован свитчер (reservation=0), нет магазинов -{red}(`data.`)`cities`пустой в ответе метода  `GET product/product/product-cities/{product_id}`
текст: "**Этого размера сейчас нет в магазинах вашего города. Попробуйте выбрать другой размер или оформите онлайн-заказ с доставкой**"

++Кейс 3++: заходим в раздел, размер выбран (barcode передан), активирован свитчер "можно забронировать" (reservation=1), доступны другие размеры, то есть когда пустой `data.cities` в ответе метода `GET product/product/product-cities/{product_id} `и есть размеры в `GET/store-availability`
текст: "**Этот размер недоступен для бронирования. Попробуйте выбрать другой размер или сбросьте фильтр бронирования, чтобы проверить наличие в магазинах"**

++Кейс 4++: заходим в раздел, размер выбран (barcode передан), активирован свитчер "можно забронировать" (reservation=1), другие размеры недоступны, то есть когда в `data.cities`пустой массив в ответе метода `GET product/product/product-cities/{product_id}`и нет размеров в `GET /store-availability`
текст: "**Изделие недоступно для бронирования. Сбросьте фильтр бронирования, чтобы проверить наличие в магазинах"**

++Кейс 5++: заходим в раздел, размер НЕ выбран (barcode не передан), активирован свитчер "можно забронировать" (reservation=1), когда в `data.cities`пустой массив  в ответе метода `GET product/product/product-cities/{product_id}`
текст: "**Изделие недоступно для бронирования. Сбросьте фильтр бронирования, чтобы проверить наличие в магазинах**"

{% note info "Важно!" %}

1. Если выбран город не РФ, то переключатель "Можно забронировать" необходимо скрывать, размер и город можно менять
2. Активный фильтр "Можно забронировать" учитываем только при отображении магазинов, при переходе к списку городов или размеров показываем данные независимо от возможности бронирования. Если пользователь выбирает город, в котором бронирование недоступно, то при возврате к выбору магазина необходимо скрывать фильтр "Можно забронировать"
3. При переходе к списку магазинов берется город из профиля и пользователю необходимо менять город. На фронте необходимо запоминать последний выбранный пользователем город в списке магазинов и его передавать при следующем переходе к бронированию

{% endnote %}

## **Тестирование**

{% cut "Критерии приёмки" %}

1. По клику на блок сразу открывается список магазинов
2. Список и размеры соответствуют ответу `GET/product-cities`
3. Текст для пустых состояний соответствует описанию
4. Фильтр "Выберите размер" по умолчанию показывает "Не выбран"; по клику открывается попап с размерами
5. Выбор размера обновляет значение фильтра и фильтрует список магазинов
6. Переключатель "Можно забронировать" фильтрует список и корректно комбинируется с фильтром по размеру

{% endcut %}
