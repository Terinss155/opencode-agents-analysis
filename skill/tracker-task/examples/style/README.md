# Образцы стиля: задачи С. Щербатых (офлайн-копии)

Копии эталонных задач по типам из `SKILL.md` §7, «Образцы в Трекере». Нужны, чтобы работа не останавливалась без доступа к Трекеру.

**Как пользоваться**
- Есть доступ к Трекеру — сверяться с оригиналом по ключу: копия могла устареть.
- Нет доступа — ориентироваться на копию. Остальные образцы из таблицы §7 есть только в Трекере.
- Копия — образец **способа изложения**, а не правил. При расхождении с `SKILL.md` §7 и шаблонами действуют они: часть её практики не перенимается (таблица «Не перенимается»).

**Как сделаны копии** (17.11.2026, из Трекера)
- Текст описания — дословно, включая её опечатки (их не перенимать).
- Таблицы Трекера `#| … |#` переведены в markdown, якоря `{#…}` убраны, вложенные картинки заменены пометкой `[скриншот]`.
- Реальные идентификаторы клиента и окружения заменены плейсхолдерами — помечено в файле.
- Метаданные (исполнители, спринты, SLA) не копируются.
