# [B][Mobile API][Gate] <Раздел/фича>. <Метод для чего>

## Цель

Реализовать метод-заглушку для <что делает метод>

## Описание реализации

В рамках данной задачи реализуется метод-заглушка. Реализация логики будет в рамках задачи https://tracker.yandex.ru/<KEY>

```
Gate: <МЕТОД> /api/v1/<путь>
```

Результатом выполнения данной задачи будет возможность отправить запрос и получить в ответ заглушку, чтобы МП могли выпустить релиз без логики.

Пример ответа:

```json
{
  "success": true,
  "result": {
  }
}
```

## Тестирование

{% cut "Критерии приёмки" %}

1. При вызове метода `<МЕТОД> /api/v1/<путь>` возвращается ответ-заглушка

{% endcut %}
