### Взаимодействие компонентов

**Мобильное приложение**

{% cut "Sequence" %}

```mermaid
sequenceDiagram
    autonumber
    actor U as Пользователь
    participant APP as App
    participant API as Mobile-API
    participant MON as Monolith
    participant EXT as Внешняя система

    U->>APP: Действие пользователя
    APP->>API: GET /получить …
    API->>MON: GET /получить …
    MON->>EXT: Запрос во внешнюю систему
    EXT-->>MON: Ответ
    MON-->>API: Ответ
    API-->>APP: Ответ
    APP-->>U: Результат
```
{% endcut %}
